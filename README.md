# Hospital DBMS

A browser-based hospital database management system demo for organizing hospital operations and records.

## Overview

This project presents a hospital database management system designed to model common healthcare workflows. The interactive HTML demo is supported by a research paper and presentation covering the project's background, design, and implementation.

## Features

- Interactive hospital DBMS interface
- Structured documentation of the database project
- Research paper and presentation for project background and results

## Getting Started

```bash
git clone https://github.com/mayankswaraj18cr-cmd/Semester--4-Project-.git
cd Semester--4-Project-
```

Open [src/hospital_dbms.html](src/hospital_dbms.html) in a web browser to view the demo. No build step or server is required.
